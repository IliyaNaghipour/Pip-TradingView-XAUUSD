# پیپ — اندیکاتور فرکتال / روند / اردر بلاک / ۱-۲-۳ / فلگ | طلا (XAUUSD)

این اندیکاتور آموزشی است، سیگنال خرید و فروش نیست.
اول فقط روی حساب دمو تست کن. طلا خیلی پرنوسان است.

هر دو نسخه یک منطق را نشان می‌دهند، فقط برای طلا تنظیم شده‌اند:
- فرکتال بیل ویلیامز (۵ کندل)
- روند با EMA 50 / EMA 200 و پس‌زمینه سبز / قرمز
- اردر بلاک صعودی (سبز) و نزولی (قرمز) — باکس، تا وقتی قیمت از آن عبور کند باقی می‌ماند
- الگوی ۱-۲-۳ — وقتی نقطه ۲ شکسته شود
- فلگ صعودی / نزولی — وقتی پولبک کم‌عمق شکسته شود
- هشدار برای لمس اردر بلاک، شکست ۱-۲-۳، شکست فلگ و شکست فرکتال

تنظیم پیش‌فرض برای طلا: جابه‌جایی اردر بلاک حداقل ۱٫۰ برابر ATR(14)،
میله فلگ حداقل ۱٫۵ برابر ATR در ۵ کندل، اصلاح فلگ حداکثر ۵۰٪ میله.
بهترین تایم‌فریم پیشنهادی: H1 برای روند و ساختار، M15 برای ورود.

## نسخه ۱ — TradingView (برای گوشی، بهترین گزینه)

این نسخه روی گوشی هم کامل دیده می‌شود.

۱. در TradingView یک چارت XAUUSD باز کن (مثلاً OANDA:XAUUSD یا نماد طلای بروکرت).
۲. پایین صفحه Pine Editor را باز کن.
۳. فایل `Pip_Fractal_OB_Flag_XAUUSD.pine` را باز کن، همه متن را کپی کن و در Pine Editor بچسبان.
۴. روی Add to chart بزن.
۵. برای هشدار: روی چارت راست‌کلیک کن ← Add Alert ← Condition را روی همین اندیکاتور بگذار
   (مثلاً OB Bull Touch یا Bull Flag Break) و Once Per Bar Close را انتخاب کن.
   هشدارهای TradingView به گوشی‌ات می‌آیند.

## نسخه ۲ — MetaTrader 5 دسکتاپ (برای کامپیوتر)

این نسخه روی گوشی MT5 نصب نمی‌شود. فقط روی MT5 دسکتاپ ویندوز / مک کار می‌کند.

۱. در MT5 دسکتاپ، F4 را بزن تا MetaEditor باز شود.
۲. فایل `Pip_Fractal_OB_Flag_XAUUSD.mq5` را در پوشه `MQL5/Indicators/` بگذار.
   مسیر معمول در ویندوز:
   `File → Open Data Folder → MQL5 → Indicators`
۳. در MetaEditor فایل را باز کن و F7 را بزن تا کامپایل شود. باید ۰ خطا بدهد.
۴. در MT5، از پنجره Navigator → Indicators آن را روی چارت XAUUSD بکش.
۵. برای اینکه هشدار به گوشی‌ات بیاید:
   Tools → Options → Notifications → MetaQuotes ID گوشی‌ات را وارد کن.
   MetaQuotes ID را در اپ MT5 گوشی، از قسمت Settings / Messages پیدا می‌کنی.
   در تنظیمات اندیکاتور، InpPush را true بگذار.

نکته: اگر کامپیوترت خاموش شود، اندیکاتور هم خاموش می‌شود. برای هشدار ۲۴ ساعته
به یک VPS نیاز داری که MT5 همیشه روشن باشد.

## چطور با آن کار کنی — چک‌لیست

۱. روند H1 چیست؟ سبز (صعودی) یا قرمز (نزولی)؟ فقط در جهت روند معامله کن.
۲. اردر بلاک تازه و در جهت روند کجاست؟ صبر کن قیمت به آن برگردد.
۳. موقع برگشت، فرکتال، کندل برگشتی، ۱-۲-۳ یا فلگ تایید می‌کند؟
۴. حد ضرر زیر اردر بلاک / زیر نقطه ۳، حد سود تا نقدینگی بعدی،
   نسبت ریسک به ریوارد حداقل ۱ به ۲. ریسک هر معامله بیشتر از ۱٪ سرمایه نباشد.
۵. اگر یک مرحله جوابش «نه» بود، معامله نکن.
